ExpensePro - arquivos separados por tela

Cada tela tem seu próprio arquivo HTML, CSS e JavaScript.
O arquivo css/base.css guarda os estilos comuns; cada CSS de tela guarda
somente os estilos específicos daquela parte.

Os formulários, filtros e relatórios são estruturas iniciais. Completem
as funções em js/ conforme aprendem e decidam como guardar as despesas.

Para abrir corretamente os arquivos JavaScript no navegador, iniciem um
servidor local na pasta do projeto. Exemplo: python -m http.server
Depois acessem http://localhost:8000.
